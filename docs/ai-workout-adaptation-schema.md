# AI Workout Adaptation Schema

This note documents the extra workout-tracking fields introduced for AI-generated prescriptions and session adaptation.

## Goal

Separate what the AI prescribed from what the user actually did so later plans can adapt based on real execution data.

## New Concepts

- `planned_*`: the workout prescription generated by AI or cloned from the weekly plan
- `actual_*`: the workout values the user really used after editing a session
- `completed_sets`: how many sets were actually completed so far
- `daily_exercise_set_logs`: one row per performed set for progression logic

## Tables Updated

### `weekly_plan_exercises`

Added:

- `planned_sets`
- `planned_reps`
- `planned_weight_kg`
- `planned_rest_seconds`
- `target_rpe`
- `estimated_kcal`
- `ai_note`
- `load_instruction`

These fields keep the AI prescription on the weekly plan itself.

### `daily_exercise_sessions`

Added:

- `weekly_plan_exercise_id`
- `planned_sets`
- `planned_reps`
- `planned_weight_kg`
- `planned_rest_seconds`
- `actual_sets`
- `actual_reps`
- `actual_weight_kg`
- `actual_rest_seconds`
- `target_rpe`
- `estimated_kcal`
- `actual_kcal_estimated`
- `completed_sets`
- `load_adjustment_note`

This is the main source for "what was planned today" vs "what the customer actually changed to."

### `daily_workout_session_exercises`

Added:

- `daily_exercise_session_id`
- `weekly_plan_exercise_id`
- `planned_sets`
- `planned_reps`
- `planned_weight_kg`
- `planned_rest_seconds`
- `actual_sets`
- `actual_reps`
- `actual_weight_kg`
- `actual_rest_seconds`
- `target_rpe`
- `estimated_kcal`
- `actual_kcal_estimated`
- `completed_sets`

This keeps the dedicated workout-session table aligned with the daily exercise session snapshot.

## New Table

### `daily_exercise_set_logs`

Tracks each performed set:

- `daily_exercise_session_id`
- `workout_session_exercise_id`
- `set_number`
- `planned_reps`
- `target_weight_kg`
- `actual_reps`
- `actual_weight_kg`
- `rest_seconds`
- `rpe`
- `estimated_kcal`
- `notes`
- `is_completed`

## Adaptation Flow

1. AI creates weekly plan rows with `planned_*`, `target_rpe`, `estimated_kcal`.
2. Daily session rows are cloned from the plan and initialize `actual_* = planned_*`.
3. If the user changes weight, reps, or sets, only `actual_*` changes.
4. Each completed set is written to `daily_exercise_set_logs`.
5. Future AI generations can read:
   - prescribed load
   - actual load used
   - completion count
   - set-level execution
   - session feedback

This is the minimum schema needed for reliable progression and auto-adjustment.
